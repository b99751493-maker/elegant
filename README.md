# ELEGANT — Guliston o‘quv markazi

Professional, animatsiyali o‘quv markazi sayti. HTML, CSS va Vanilla JavaScript ishlatilgan; framework talab qilinmaydi.

## Ishga tushirish
1. `ELEGANT` papkasini VS Code’da oching.
2. `index.html` faylini Live Server orqali ishga tushiring yoki faylni brauzerda oching.
3. Google Fonts va Unsplash rasmlari uchun internet aloqasi kerak bo‘lishi mumkin.

## Sayt imkoniyatlari
- Responsive navigatsiya va scroll animatsiyalari
- 18 ta kurs kartasi va kategoriya filtrlari
- Kurs tafsilotlari modal oynasi
- Maqsadga qarab yo‘nalish tavsiya qiluvchi mini-so‘rovnoma
- FAQ accordion
- Sinov darsi uchun forma, demo ariza raqami va nusxalash
- Aloqa kartalari, telefon havolalari va ijtimoiy tarmoqlar
- Keyboard accessibility va mobil ko‘rinish

## Muhim
Ariza formasi hozircha brauzerning localStorage xotirasiga saqlaydi va markazga yubormaydi. Haqiqiy arizalarni qabul qilish uchun backend yoki tasdiqlangan Telegram/email integratsiyasi qo‘shilishi kerak. Kurs narxlari va davomiyliklar foydalanuvchi yuborgan buklet asosida kiritildi; bukletda ko‘rsatilmagan ma’lumotlarni markaz bilan aniqlashtirish kerak.
